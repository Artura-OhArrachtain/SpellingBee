✳ SpellingBee Back to checker
BROWSER EXTENSION

Check writing where you write.

Download the extension package. It is preconfigured to connect to this SpellingBee app.

Download for Chrome or Edge (.zip) Download for Firefox (.xpi)

Install in Chrome or Edge

  1. Unzip the downloaded file into a folder you can keep.
  2. Open chrome://extensions or edge://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder containing manifest.json.
  4. Open an online writing page, select text or click in its editor, then open SpellingBee from the extensions menu.
  5. The first time, press Save in the extension popup and allow it to connect to this SpellingBee app.

Install in Firefox

  1. Download the Firefox .xpi package above.
  2. Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select the downloaded .xpi file.
  3. Open an online writing page, select text or click in its editor, then open SpellingBee from the toolbar.
  4. The first time, press Save in the extension popup and allow it to connect to this SpellingBee app.

Firefox temporary add-ons are removed when Firefox closes. Permanent installation requires publishing through Mozilla Add-ons. Google Docs has a separate sidebar integration under integrations/google-docs.
